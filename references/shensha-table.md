# 神煞表

神煞只是辅助，不能单独论命。论命以日主旺衰、格局、用神为主，神煞只作旁证。

本表是本仓库**唯一神煞口径**，与 `scripts/pai_pan.py` 的计算规则完全一致。排盘只输出命局实际命中的条目；时柱未知时，不得用时柱凑神煞。

## 关于出处与命中率（务必先读）

- 出处：《三命通会》《渊海子平》通行口径。个别条目各书有分歧，已在条目下注明取法。
- **命中率差异很大，看的时候要分清**。以下是 1980–2000 年间 1143 个抽样命例的实测命中率：

  | 量级 | 神煞 | 参考意义 |
  |---|---|---|
  | 极常见（60% 以上） | 太极贵人、天乙贵人、福星贵人、天厨贵人、将星、华盖、德秀贵人、劫煞、亡神 | 命中属常态，**不宜单独当作命局特征** |
  | 常见（30–60%） | 国印贵人、童子煞、文昌、学堂、词馆、禄神、羊刃、空亡、孤辰、驿马 | 可作旁证 |
  | 少见（10–30%） | 天德、月德、金舆、桃花、灾煞、元辰、天医、金神、血刃、十恶大败、天罗地网、寡宿 | 值得留意 |
  | 稀有（10% 以下） | 六秀日、魁罡、天赦 | 有区分度 |

  命中率由「查表支数 ÷ 12」决定：一个天干若对应 2 个地支，单查就有约 17%
  （四柱四个地支位取「或」，实际约 50%）。这不是计算错误，是古籍原表的固有特征。

## 吉

### 天乙贵人

- **名称**：天乙贵人
- **吉凶**：吉
- **查法**：按**年干或日干**查四柱**地支**。年干、日干各自对应的贵人支，出现在年支、月支、日支、时支则见（时柱未知不计时支）。
- **口诀或查表**：
  - 甲戊 → 丑未
  - 乙己 → 子申
  - 丙丁 → 亥酉
  - 壬癸 → 卯巳
  - 庚 → 丑未寅午（「甲戊庚牛羊」与「庚辛逢虎马」取并集）
  - 辛 → 寅午

### 天赦

- **名称**：天赦（天赦日）
- **吉凶**：吉

- **口诀或查表**：春（寅卯辰月）戊寅日；夏（巳午未月）甲午日；秋（申酉戌月）戊申日；冬（亥子丑月）甲子日。

### 童子煞

- **名称**：童子煞
- **吉凶**：凶
- **查法**：两条口诀任一命中**日支或时支**即见（时柱未知不计时支）：
  - 按季节：春秋（寅卯辰、申酉戌月）见寅子；冬夏（亥子丑、巳午未月）见卯未辰。
  - 按年柱纳音：金木命见午卯；水火命见酉戌；土命见辰巳。
- **口诀或查表**：「春秋寅子贵，冬夏卯未辰；金木马卯合，水火鸡犬多，土命逢辰巳。」
- **备注**：此煞民间说法多，本表取上述通行口径，仅作提示，不可据此断命。

### 天罗地网

- **名称**：天罗地网
- **吉凶**：凶
- **查法**：男查辰（天罗），女查戌（地网）。该地支出现在**月支、日支、时支**则见（不计年支；时柱未知不计时支）。
- **口诀或查表**：男怕天罗（辰），女怕地网（戌）。
